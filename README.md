# Evertome · web

Página pública de [Evertome](https://perfectime94.github.io/evertome-site/), addon para World of Warcraft: Forever,
y de su acompañante Evertome Sync. HTML y CSS estáticos, bilingüe (español / inglés), sin recursos externos.

- `index.html`: contenido (cada texto en `<span lang="es">` y `<span lang="en">`).
- `assets/style.css`, `assets/main.js` (selector de idioma), `assets/icon.png` (de `tools/IconGen` en evertome-sync).
- Publicación: GitHub Pages desde la rama `main`, carpeta raíz.
